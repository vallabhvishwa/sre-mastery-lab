# One-hour session protocol

Use [`docs/ONE_HOUR_PROTOCOL.md`](../docs/ONE_HOUR_PROTOCOL.md) as the canonical minute-by-minute protocol and [`sessions/PLAYGROUND_SESSION_CARDS.md`](PLAYGROUND_SESSION_CARDS.md) to choose the correct KodeKloud playground. Keep one main playground per session, create one durable report, and never assume playground state persists after reset.
